# Contributing

Thanks for helping with Snipio. Issues and small, focused pull requests are welcome.

1. Use Node.js 22+ and load `extension/` as an unpacked extension.
2. Make your change without adding accounts, telemetry, or a required service.
3. Run `npm test` and `npm run check`.
4. For UI or expansion changes, run the relevant browser tests in [tests/README.md](tests/README.md).
5. Describe the problem, the change, and how you checked it in your pull request.

Use synthetic snippets and a disposable browser profile when testing. Do not attach real backup files, clipboard contents, credentials, or personal information to public issues.

New code and artwork must be original or come with a compatible license and attribution. Record third-party material in [docs/THIRD_PARTY_NOTICES.md](docs/THIRD_PARTY_NOTICES.md). Contributions are submitted under the project's [GPL-3.0-or-later license](LICENSE). The project name and logo are not covered by this license.
